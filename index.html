Packs 隐私政策

最后更新：2026-04-13

1. 数据收集

本应用不会收集任何个人数据。所有代码和对话均在用户本地设备上处理，不会发送到任何服务器。

2. 数据存储

代码文件：仅存储在用户指定的本地目录
对话历史：仅存储在用户本地设备
设置偏好：存储在本地 UserDefaults

3. 第三方 SDK

本应用使用 Ollama 本地模型框架，完全本地运行，无需网络连接。

4. 数据共享

本应用不会与任何第三方共享用户数据。

5. 儿童隐私

本应用不面向13岁以下儿童。

6. 联系我们

邮箱：projectpilot@email.com

本隐私政策适用于 Packs macOS 应用
