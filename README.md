## 核心特性

### 本地运行，数据不外泄
代码和对话仅在本地处理，不会发送到任何服务器。

### 多 Agent 协作
架构师 + 开发者 + 测试员分工合作，模拟真实开发团队。

### Apple 开发者首选
深度支持 Swift/SwiftUI，专为 macOS 原生开发优化。

### 隐私优先
无需账号，无需登录，开箱即用。

## 技术栈

- **前端**: SwiftUI + TCA
- **后端**: Python + FastAPI + WebSocket
- **模型**: Ollama (本地运行)
- **平台**: macOS
